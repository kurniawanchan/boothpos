**Profil Saya** adalah satu-satunya layar pengaturan yang dapat dibuka setiap pengguna yang sudah masuk, apa pun perannya. Layar ini hanya mengubah akun Anda sendiri.

## Sebelum mulai

- Tidak ada izin menu yang diperlukan. Layar ini tidak punya kunci menu, sehingga peran kasir, inventory, dan peran kustom juga dapat memakainya.
- Buka dari nama Anda di kanan atas aplikasi: klik nama itu lalu pilih **Profil**.
- Untuk mengubah foto, nama, peran, atau password orang lain, owner atau admin memakai [Pengguna](/settings/users).

## Isi layar

| Item | Catatan |
| --- | --- |
| **Foto profil** | Foto Anda saat ini, atau inisial Anda bila belum punya foto. |
| **Nama** | Hanya baca. |
| **Username** | Hanya baca. Ini yang Anda ketik untuk masuk. |
| **Peran** | Hanya baca. |

Anda tidak dapat mengubah nama, username, atau peran di sini. Minta owner atau admin.

## Mengganti foto

<Steps>
  <Step title="Klik Ganti foto">
    Pemilih berkas terbuka.
  </Step>
  <Step title="Pilih gambar">
    JPEG atau PNG, maksimal 5 MB.
  </Step>
  <Step title="Selesai">
    Pengunggahan dimulai seketika. Anda melihat **Foto profil berhasil diubah.** dan foto baru menggantikan yang lama.
  </Step>
</Steps>

Bila server menolak berkas (tipe salah atau terlalu besar), alasannya muncul di bawah foto dan foto lama Anda tetap.

## Mengganti password

<Steps>
  <Step title="Masukkan password Anda saat ini">
    Ketik di **Password saat ini**.
  </Step>
  <Step title="Masukkan password baru dua kali">
    Ketik password baru di **Password baru** dan sekali lagi di **Konfirmasi password baru**.
  </Step>
  <Step title="Simpan">
    Klik **Simpan password**. Anda melihat **Password berhasil diubah.** dan ketiga kolom dikosongkan.
  </Step>
</Steps>

Aturan yang ditegakkan server (422, ditampilkan di bawah kolom):

| Kolom | Aturan |
| --- | --- |
| **Password saat ini** | Wajib. Bila salah: **Password saat ini salah.** dan tidak ada yang berubah. |
| **Password baru** | Wajib, dan harus memenuhi aturan password bawaan Laravel. Kode tidak menetapkan aturan kustom, sehingga artinya panjang minimal 8 karakter (akun yang dibuat administrator punya minimum 8 karakter yang sama). |
| **Konfirmasi password baru** | Harus sama dengan **Password baru**. |

Mengganti password tidak mengeluarkan Anda dari sesi yang sedang Anda pakai. Administrator yang mereset password Anda dari [Pengguna](/settings/users) adalah tindakan yang berbeda.

<Note>
  Layar ini hanya mengubah password masuk Anda. PIN masuk tablet diatur oleh owner atau admin dari [Pengguna](/settings/users); tidak ada kolom PIN di profil Anda.
</Note>

## Pemecahan masalah

| Pesan atau gejala | Penyebab | Solusi |
| --- | --- | --- |
| **Password saat ini salah.** | Password saat ini salah ketik. | Ketik ulang. Bila Anda lupa, minta owner atau admin mereset password Anda di [Pengguna](/settings/users). |
| Pesan tentang konfirmasi password baru | Kedua password baru berbeda. | Ketik ulang keduanya. |
| Pesan tentang panjang password baru | Kurang dari 8 karakter. | Pakai password yang lebih panjang. |
| Foto ditolak | Bukan JPEG atau PNG, atau lebih dari 5 MB. | Pilih berkas lain. |
