The **Materials** page is the master list of everything you buy to make or pack your items: raw materials, semi-finished materials and packaging. For each material you can set the unit, correct its stock at an outlet, and record which vendors sell it and at what price.

Materials connect to the rest of the system in three places:

- **Purchase orders** buy materials from vendors. Receiving a purchase order adds the quantity to the material's stock. See [Purchase orders](/purchasing/purchase-orders).
- **Recipes and BOM** (the list of materials and services used to make one finished item) take their material cost from vendor prices. See [Product detail](/inventory/product-detail).
- The same list also appears as tabs on the Products page (Raw material, Semi-finished, Packaging), with the same form and actions.

## Before you start

- Your role needs the **Materials** menu (`materials`). The default Owner, Admin and Inventory roles have it. The default Cashier role does not.
- Create at least one vendor on the [Vendors](/purchasing/vendors) page before you add vendor prices.
- Stock adjustment and vendor prices are gated by the same Materials menu.

## The materials table

| Column | What it shows |
| --- | --- |
| Code | Material code. |
| Name | Material name. |
| Kind | Raw material, Semi-finished or Packaging. Hidden when the table is limited to one kind (on the Products tabs). |
| Unit | Free-text unit, for example pcs, meter, gram. |
| Stock | Current stock. With more than one outlet visible, one value per outlet in the form `CODE amount`, separated by dots. With one outlet, a single number. |
| Vendors | Number of vendors that have a price for this material. |
| Status | Active or Inactive. |

Search filters by material name (about 300 ms after you stop typing). **Reset filters** clears it. The list is sorted by name.

## Add a material

<Steps>
  <Step title="Open the form">
    Select **Add material**.
  </Step>
  <Step title="Fill in the fields">
    **Material code**, **Material name**, **Material kind** and **Unit** are required.
  </Step>
  <Step title="Save">
    Select **Save**. You see "Material created."
  </Step>
</Steps>

| Field | Required | Rules |
| --- | --- | --- |
| Material code | Yes | Up to 20 characters, letters, numbers, dashes and underscores. Saved in uppercase. Unique among materials that are not deleted. Permanent after creation. |
| Material name | Yes | Up to 150 characters. |
| Material kind | Yes | **Raw material**, **Semi-finished** or **Packaging**. New materials default to Raw material. |
| Unit (e.g. pcs, meter, gram) | Yes | Up to 20 characters. |
| Standard cost per unit | No | Shown only for **Semi-finished**. Zero or more. Recipes use it when a semi-finished material has no vendor price. |
| Notes | No | Free text. |
| Active | No | Checked by default. |

When you edit a material, the code is locked. The standard cost is only sent when the kind is Semi-finished, so changing the kind to something else does not overwrite a saved standard cost.

## Adjust stock

Material stock is a balance per outlet. Use **Adjust stock** to correct it, for example after a stock count.

<Steps>
  <Step title="Open the dialog">
    Select **Adjust stock** on the row. The title reads "Adjust stock of \{name\}".
  </Step>
  <Step title="Choose the outlet">
    This field only shows when you can see more than one outlet. It defaults to the outlet chosen in the top bar. With one outlet, the server uses that outlet.
  </Step>
  <Step title="Enter the change">
    Enter **Change (+/−)**: a positive number adds stock, a negative number removes it. This is the difference, not the final quantity. Zero is not allowed.
  </Step>
  <Step title="Enter a reason and save">
    Enter a **Reason** (up to 255 characters). **Save** stays disabled until the change is not zero, the reason is filled and, with several outlets, an outlet is chosen. You see "Material stock adjusted".
  </Step>
</Steps>

Every adjustment is written as a stock movement and to the [Activity log](/insight/activity-log) with the reason.

<Warning>
An adjustment cannot make an outlet's balance negative. The server rejects it with a 422 error under **Change (+/−)**: "Insufficient stock for material \{name\} (available: \{number\})", followed by the outlet name.
</Warning>

## Vendor prices

Select **Vendor prices** on a row. The dialog is titled "Vendor prices — \{material\}" and lists every vendor with a price for this material, with a **Preferred** badge on one of them.

The note in the dialog explains the rule: the vendor marked **Preferred** is the cost reference for this material. If none is preferred, the cheapest price is used as the estimate.

<Steps>
  <Step title="Add a price">
    Select **Add vendor price**, choose the **Vendor**, enter **Price per unit** (zero or more) and optional **Notes**.
  </Step>
  <Step title="Mark the preferred vendor (optional)">
    Check **Make this vendor preferred for this material**. Only one vendor can be preferred per material. Marking one clears the flag on the others.
  </Step>
  <Step title="Save">
    Select **Save**. You see "Vendor price added."
  </Step>
</Steps>

To change a price, use **Edit** on its row. The vendor cannot be changed there. Delete the price and add it again for another vendor. **Delete** asks "Delete the price from \{vendor\}?" and removes only that price.

The vendor picker lists active vendors only (up to 100). A vendor can have only one price per material. Adding a second one fails with "This vendor already has a price for this material. Update it via the update endpoint instead."

<Note>
ASSUMPTION: the quoted message for a duplicate vendor price mentions an "update endpoint". That text is shown as is. Use **Edit** on the existing price in the screen.
</Note>

## Delete a material

Select **Delete**, then **Yes, delete**. The dialog says "Delete \{name\}? Rejected if it still has vendor prices or BOM lines."

| Message (409) | Cause |
| --- | --- |
| This material still has registered vendor prices and cannot be deleted. | At least one vendor price exists. Delete the prices first. |
| This material is still used in a product variant's BOM and cannot be deleted. | A BOM line uses it. Remove it from the BOM first. |

## Import and export

**Export .xlsx** and **Bulk import** work the same way as on the Vendors page: the shared master-data workbook, preview first, all-or-nothing. See [Vendors](/purchasing/vendors#import-and-export). The buttons show only for users with the Materials menu.

## Troubleshooting

| What you see | Cause | What to do |
| --- | --- | --- |
| Stock shows one number although you have several outlets | Your account is assigned to one outlet only. | Ask an owner to assign more outlets. See [Outlets](/people/outlets). |
| 403 on **Adjust stock** with "This outlet is not one you are allowed to access." | You picked an outlet outside your assignment. | Choose one of your outlets. |
| 409 when adjusting: "This account is not assigned to any outlet." | Your user has no outlet assigned. | Ask an administrator to assign an outlet. |
| 422 "Choose the outlet whose stock this changes." | You can see several outlets and sent none. | Pick an outlet in the dialog. |
| Vendor missing from the price form | The vendor is inactive, or there are more than 100 vendors. | Activate it on [Vendors](/purchasing/vendors). |
