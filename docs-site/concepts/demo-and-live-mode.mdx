BoothPOS menyimpan dua set data bisnis yang terpisah dalam database yang sama: **DEMO** dan **LIVE**. Lencana di bilah atas selalu menunjukkan mode yang aktif, untuk semua peran.

| Mode | Menampilkan | Gunakan untuk |
| --- | --- | --- |
| DEMO | Data contoh untuk menjelajahi aplikasi | Pelatihan dan mencoba fitur |
| LIVE | Hanya data yang benar-benar dibuat toko Anda | Perdagangan sungguhan |

Instalasi baru dimulai dalam **LIVE**. Instalasi tidak pernah diam-diam dimulai dalam DEMO.

## Cara kerjanya

- Catatan bisnis dan transaksi (produk, stok, order, sesi, pelanggan, dan sejenisnya) diberi cap mode yang aktif **saat catatan itu dibuat**.
- Setiap daftar dan laporan hanya menampilkan catatan dari mode yang aktif.
- Berpindah mode **tidak pernah menghapus** data di kedua mode. Pindah kembali dan catatannya ada.
- Pengguna, peran, pengaturan, entri log aktivitas, dan kanal pembayaran bersifat bersama. Semuanya tidak berubah mengikuti mode.

<Warning>
  Penjualan yang dicatat dalam mode DEMO tidak muncul di laporan LIVE, dan sebaliknya. Sebelum membuka toko untuk perdagangan sungguhan, pastikan lencana bertuliskan **LIVE**.
</Warning>

## Berpindah mode

Owner dan admin (siapa pun dengan menu `settings`) berpindah mode dari **Pengaturan → General → Mode sistem**.

<Steps>
  <Step title="Buka pengaturan General">
    Buka **Pengaturan → General** dan temukan **Mode sistem**. Lihat [Pengaturan umum](/settings/general).
  </Step>
  <Step title="Pilih mode">
    Pilih DEMO atau LIVE.
  </Step>
  <Step title="Konfirmasi">
    Konfirmasikan prompt: "Pindah ke mode \{mode\}? Daftar dan laporan yang tampil akan berubah mengikuti mode ini." Sebuah toast mengonfirmasi perpindahan.
  </Step>
</Steps>

<Note>
  Lencana baru muncul setelah pengaturan selesai dimuat, sehingga Anda tidak pernah melihat mode tebakan saat halaman dimuat.
</Note>

## Nilai unik harus unik di kedua mode

Beberapa nilai, seperti kode produk, harus unik di seluruh database. Server memeriksa kedua mode, sehingga kode yang dipakai catatan DEMO tidak dapat dipakai ulang di LIVE. Jika Anda mendapat galat validasi "sudah dipakai" untuk kode yang tidak dapat Anda temukan, periksa mode yang lain.

<Note>
  ASUMSI: ini hanya memengaruhi nilai yang didefinisikan unik di seluruh database. Kolom mana saja yang termasuk ditentukan per layar. Halaman setiap modul mencatatnya di bagian yang relevan.
</Note>
