Staf masuk di tablet dengan **PIN 6 digit**, bukan username dan kata sandi. Layar masuknya bernama **Siapa yang bertugas?**. Layar ini menampilkan staf outlet tablet tersebut, lalu Anda mengetuk nama Anda dan memasukkan PIN.

## Sebelum mulai

- Tablet sudah menyimpan outlet dan terminal. Lihat [Siapkan terminal](/android/setup).
- Akun Anda aktif, ditugaskan ke outlet ini, dan memiliki PIN. Orang tanpa PIN tampil redup dan tidak dapat dipilih.
- Akun pemilik dan admin tidak muncul di daftar. Mereka tidak dapat masuk di tablet, tetapi dapat menyetujui aksi dengan PIN mereka. Lihat [Persetujuan](/android/approvals).

## Masuk

<Steps>
  <Step title="Pilih nama Anda">
    Ketuk nama Anda pada deretan chip staf. Setiap chip menampilkan inisial, nama, dan peran Anda. Orang pertama yang dapat masuk dipilihkan otomatis, jadi pastikan itu Anda.
  </Step>
  <Step title="Masukkan PIN">
    Pesan di layar berbunyi **PIN** diikuti nama Anda. Tekan angka di keypad. Enam titik terisi saat Anda mengetik. Tombol hapus (backspace) menghapus digit terakhir.
  </Step>
  <Step title="Tunggu pemeriksaan">
    PIN dikirim pada digit keenam. Tidak ada tombol konfirmasi. PIN yang benar membuka layar pertama Anda.
  </Step>
</Steps>

### Layar tujuan

| Peran di server | Layar pertama |
| --- | --- |
| **Kasir** tanpa shift terbuka | **Buka shift**, untuk membuka shift. Lihat [Shift](/android/shifts). |
| **Kasir** dengan shift terbuka | **Meja** |
| **Waiter** | **Meja** |
| Peran lain (misalnya supervisor, manajer) | **Order** |

<Note>
  Nama peran yang tidak dikenali aplikasi diperlakukan sebagai kasir. ASUMSI: peran kustom karenanya masuk ke **Buka shift** atau **Meja**, bukan **Order**.
</Note>

Aplikasi tidak membuka pesanan apa pun sendiri saat masuk. Tab terbuka yang kosong akan menghalangi penutupan shift.

## Kontrol di layar

| Kontrol | Fungsi |
| --- | --- |
| Chip staf | Memilih orang itu dan menghapus PIN serta galat yang sudah diketik. Chip yang redup tidak bereaksi. |
| Keypad | Memasukkan digit, maksimal 6. Nonaktif saat pemeriksaan berjalan atau saat tidak ada yang punya PIN. |
| **Ganti outlet / terminal** | Membuka penyiapan terminal. Pada tata letak tablet, ikon roda gigi di panel kiri melakukan hal yang sama. |
| Chip koneksi | **Online**, **Offline**, dan seterusnya, disegarkan sekitar setiap 10 detik selama layar ini tampil. |
| Panel kiri (tablet) | Nama outlet, nama terminal, jam, dan tanggal. |

## PIN salah dan penguncian

| Yang Anda lihat | Artinya |
| --- | --- |
| "PIN salah. Sisa \{n\} percobaan." | PIN salah, tersisa \{n\} percobaan sebelum terkunci. |
| "PIN terkunci karena salah 5 kali. Coba lagi dalam \{n\} menit." | Lima kali PIN salah berturut-turut mengunci PIN Anda. Jumlah menit berasal dari server dan dibulatkan ke atas. |
| "PIN terkunci karena salah 5 kali. Coba lagi sebentar lagi." | Terkunci, tetapi server tidak memberi waktu berakhir. |
| "Pilih nama Anda terlebih dahulu." | Tidak ada nama terpilih saat digit keenam dimasukkan. |

Titik-titik dikosongkan setiap kali gagal. Kuncinya berlaku 5 menit. Kunci ini per orang dan dipakai bersama dengan PIN penyetuju, sehingga PIN penyetuju yang salah juga dihitung ke dalam lima kali yang sama. Admin dapat membuka kunci lebih awal dengan mereset PIN di web.

## Ganti pengguna

Ketuk **tombol inisial** bulat di kanan atas layar mana pun yang punya header. Aplikasi mengeluarkan Anda dan kembali ke layar PIN agar orang berikutnya dapat masuk. Tablet tidak menutup shift Anda saat ini dilakukan.

<Warning>
  Keluar tidak membatalkan tab yang terbuka dan tidak menutup shift. Tab terbuka tetap ada di server. Tutup shift sebelum Anda pulang.
</Warning>

Berganti pengguna tidak pernah meminta PIN, jadi siapa pun di tablet dapat menekan tombolnya. Tekan sebelum Anda meninggalkan tablet.

## Cara admin mengatur PIN

PIN diatur di web, tidak pernah di tablet. Pemilik atau admin yang punya akses ke menu **Pengaturan** membuka [Pengguna](/settings/users), lalu memakai **Atur PIN** atau **Reset PIN** untuk orang yang bersangkutan. Layar itu juga dapat menyarankan PIN acak. Mengatur PIN membuka kunci dan mengeluarkan orang tersebut dari sesi tablet mana pun. PIN tidak pernah ditampilkan lagi setelahnya. Lihat [Peran dan izin](/concepts/roles-and-permissions) untuk mengetahui siapa yang memegang menu **Pengaturan**.

Pesan saat daftar kosong mengarah ke hal yang sama: "Belum ada staf dengan PIN di outlet ini. Atur PIN dari akun masing-masing atau minta admin."

## Pemecahan masalah

| Pesan | Penyebab | Solusi |
| --- | --- | --- |
| "Belum ada staf dengan PIN di outlet ini…" | Tidak ada orang di outlet yang punya PIN. | Admin mengatur PIN di [Pengguna](/settings/users). |
| Nama saya tidak ada | Akun nonaktif, tidak ditugaskan ke outlet ini, atau pemilik/admin. | Periksa penugasan di Pengguna. Pemilik dan admin tidak pernah muncul. |
| Nama saya redup, **Belum ada PIN** | Akun belum punya PIN. | Minta admin mengaturnya. |
| Kartu galat dengan **Coba lagi** menggantikan daftar nama | Daftar staf tidak dapat dimuat. | Periksa koneksi dan ketuk **Coba lagi**. |
| "Terminal ini tidak berlaku lagi…" | Terminal telah dicabut. | Pilih outlet dan terminal lagi. Lihat [Siapkan terminal](/android/setup). |
| Pesan galat berisi kegagalan jaringan | Server tidak dapat dijangkau. | Lihat [Offline dan sinkronisasi](/android/offline-and-sync). |
