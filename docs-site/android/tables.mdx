**Meja** menampilkan denah outlet Anda dan membuka order dine-in. Order dine-in memakai editor yang sama dengan order counter, jadi menambah item, opsi, catatan, dan diskon bekerja seperti dijelaskan di [Order counter di tablet](/android/counter). Halaman ini membahas yang berbeda untuk meja: memilih meja, tamu, putaran ke dapur, membagi, void, dan menyerahkan bill untuk dibayar.

## Sebelum mulai

- Masuk dengan PIN, lihat [Masuk dengan PIN](/android/pin-sign-in). Kasir dan waiter masuk ke **Meja** setelah login; peran lain masuk ke **Order**.
- Membuka order baru membutuhkan shift terbuka: "Buka shift dulu sebelum membuka order." Lihat [Shift di tablet](/android/shifts).
- Denah berasal dari server dan disegarkan setiap 3 detik. Meja dan area diatur di web, lihat [Pengaturan restoran](/operations/restaurant-setup).
- Anda membutuhkan koneksi. Tidak ada antrean offline untuk order, lihat [Offline dan sinkronisasi](/android/offline-and-sync).

## Siapa boleh melakukan apa

| Tindakan | Membutuhkan | Jika Anda tidak berhak |
| --- | --- | --- |
| Membuka meja, menambah item, mengirim ke dapur, mencetak pre-bill | Staf mana pun yang sudah masuk | Tidak berlaku |
| Menerima pembayaran | Peran apa pun selain waiter. Tombol bayar waiter mencetak pre-bill | Minta kasir menerima pembayaran |
| Void item yang sudah dikirim ke dapur | Izin void order, atau PIN penyetuju | Lembar **Perlu persetujuan** |
| Membatalkan seluruh order | Izin pembatalan order, atau PIN penyetuju | Lembar **Perlu persetujuan** |
| Diskon di atas batas peran Anda | PIN penyetuju | Lembar **Perlu persetujuan** |

Owner dan admin memegang izin void dan pembatalan secara bawaan. Peran lain membutuhkan administrator untuk memberikannya, lihat [Peran](/settings/roles) dan [Persetujuan](/android/approvals). Ikon gembok pada **Void item** dan **Void** muncul untuk semua orang kecuali peran bernama Supervisor, Outlet Manager, owner, dan admin. Itu hanya petunjuk; server yang memutuskan.

## Denah

Chip area di atas (misalnya **Indoor**, **Teras**) berpindah antar area. Meja tanpa area masuk di bawah **Lainnya**. Pada layar lebar, sisi kanan menyatakan "Denah dari server · diperbarui tiap 3 dtk", atau "Denah terakhir · server tidak terjangkau" bila penyegaran terakhir gagal. Tarik ke bawah untuk menyegarkan seketika.

Setiap ubin menampilkan nama meja dan salah satu status berikut:

| Ubin | Arti |
| --- | --- |
| Polos, **Tersedia** | Tidak ada order terbuka. |
| Berwarna, **Terisi** | Ada order terbuka. Ubin juga menampilkan satu titik per tamu (maksimal 8), "4 tamu", dan total saat ini. |
| Berwarna dengan border tebal, **Bill tercetak** | Pre-bill sudah dicetak untuk order. |
| Abu-abu dan diarsir, **Terminal Kasir 2** | Order milik terminal lain. Anda tetap dapat membukanya. |

Saat denah dimuat Anda melihat indikator pemuatan. Jika sama sekali tidak dapat dimuat, Anda melihat galatnya dengan tombol coba lagi. Setelah pemuatan pertama berhasil, penyegaran yang gagal mempertahankan denah terakhir di layar.

<Note>
ASUMSI: Jika outlet tidak memiliki meja, grid kosong dan tablet tidak menampilkan pesan. Periksa pengaturannya di web.
</Note>

## Buka order untuk meja

<Steps>
  <Step title="Ketuk meja yang kosong">
    Lembar **Meja 5** terbuka dengan "Ketuk jumlah tamu untuk membuka order meja."
  </Step>
  <Step title="Ketuk jumlah tamu">
    Tombol 1 sampai 8. Order langsung terbuka, berjudul **Meja 5**, subjudul "Dine-in" beserta nama Anda. Untuk lebih dari 8 tamu pilih 8 (ASUMSI: tablet tidak menawarkan angka lain, padahal server menerima sampai 99).
  </Step>
  <Step title="Tambahkan item">
    Gunakan grid produk di kiri, atau bilah **Lihat order** pada layar seukuran ponsel. Lihat [Order counter di tablet](/android/counter).
  </Step>
</Steps>

Mengetuk meja yang sudah memiliki order membuka order itu, bukan membuat yang kedua. Jika dua orang membuka meja kosong yang sama pada saat yang sama, server menolak yang kedua: "Meja ini sudah punya tab yang terbuka." Penolakan lain: "Meja ini nonaktif dan tidak bisa menerima tab baru." dan, untuk terminal yang dicabut, "Terminal ini dicabut. Tidak bisa membuka order baru."

Anda juga dapat menjangkau setiap order terbuka, termasuk order bawa pulang, dari **Order** lalu **Terbuka**, lihat [Order](/android/orders). Order dengan pembayaran QRIS yang menunggu verifikasi langsung terbuka di layar pembayaran.

## Kirim item ke dapur

Item baru berada di bawah **Belum dikirim** (merah). Ketuk **Kirim N** untuk mengirim semuanya sebagai satu putaran. Item berpindah ke **Sudah dikirim ke dapur** dan masing-masing menampilkan "Terkirim 19:42". Waiter biasanya mengirim setelah setiap putaran pemesanan.

- Pesannya "3 item dikirim ke dapur · KOT dikirim ke printer", atau "... KOT belum tercetak, printer belum tersambung" bila tidak ada printer yang tersambung. Item tetap sampai ke layar dapur. Lihat [Pencetakan](/android/printing) dan [Dapur](/operations/kitchen).
- Pemberitahuan merah "KOT belum tercetak — kirim ulang ke dapur secara manual" tetap ada di panel selama tiket dapur untuk order ini menunggu atau gagal.
- **Cetak ulang KOT** di **Aksi order** mencetak ulang tiket yang sudah dikirim untuk order ini.
- Baris yang sudah dikirim tidak memiliki stepper dan tidak dapat diubah. Menghapusnya berarti void.

## Pre-bill dan menutup tab untuk pembayaran

**Cetak pre-bill** (di **Aksi order**, atau tombol utama untuk waiter) menandai order sebagai sudah ditagih di server dan mengantrekan cetakan bertanda "BELUM LUNAS". Pesannya "Pra-bill masuk antrean cetak · BELUM LUNAS." Ubin lalu menampilkan **Bill tercetak**. Anda dapat mencetaknya lagi.

Untuk menerima pembayaran, non-waiter mengetuk **Bayar**.

- Tanpa shift: **Belum ada shift terbuka** muncul dengan "Pembayaran hanya bisa diterima setelah shift terbuka. Order tetap tersimpan." dan tombol **Buka shift**.
- Jika tidak, layar pembayaran terbuka, lihat [Pembayaran](/android/payment). Saat order dibayar penuh, order menjadi penjualan dan meja kosong lagi.

## Bagi bill

Buka **Aksi order**, lalu **Bagi bill**. Ada dua mode, dipilih dengan **Per item** dan **Rata**.

### Per item

<Steps>
  <Step title="Pilih item">
    Centang baris yang masuk ke bill baru. Tombolnya berbunyi **Bayar 2 item tunai**.
  </Step>
  <Step title="Ketuk tombol">
    Baris yang dipilih dibayar tunai sebesar nominalnya dan menjadi penjualan selesai yang terpisah. Lembar lalu menampilkan **Bagian dibayar** dan **Sisa bill** dari server. Ketuk **Selesai**.
  </Step>
</Steps>

Ini membayar seketika dan hanya tunai. Membutuhkan shift terbuka. Item yang tersisa tetap di order.

### Rata

Atur **Jumlah orang** (2 sampai 5) dan ketuk **Bagi rata 3 orang**. Server mengembalikan setiap bagian ("3 bagian dari server": **Bagian 1**, **Bagian 2**, ...). Ini hanya pratinjau: tidak ada yang dibayar dan order tidak berubah. Gunakan nominalnya saat setiap tamu membayar bagiannya dari order yang sama.

Penolakan server: "Tab yang sudah punya pembayaran tidak bisa dipisah." dan "Jumlah yang dipisah melebihi jumlah ... pada tab."

<Note>
Tablet tidak memiliki kontrol untuk memindahkan order ke meja lain atau menggabungkan dua order. Server mendukung keduanya; gunakan web, lihat [Denah dan tab](/operations/restaurant-floor).
</Note>

## Void item yang sudah dikirim

Baris yang sudah dikirim ke dapur tidak dapat dihapus. Ketuk baris itu, lalu **Void item**.

<Steps>
  <Step title="Pilih alasan">
    **Salah input**, **Pelanggan batal**, **Item tidak tersedia**, atau **Kualitas / keluhan**. Yang pertama sudah dipilih sebelumnya.
  </Step>
  <Step title="Sebutkan yang dilakukan dapur">
    **Belum dibuat** mengembalikan stok. **Sudah dibuat (wastage)** mencatat stok sebagai terbuang.
  </Step>
  <Step title="Ketuk Void">
    Muncul pesan "Es Teh di-void." Slip BATAL diantrekan untuk printer dapur. Tanpa izin void, lembar **Perlu persetujuan** terbuka lebih dulu.
  </Step>
</Steps>

Jika dapur sudah mulai mengerjakan item itu, server menjawab "Status dapur berubah. Muat ulang tab lalu coba lagi." Buka ulang order dan coba lagi. Stok tidak dapat dikembalikan setelah item mulai dimasak: "Stok tidak bisa dikembalikan setelah item mulai dimasak."

## Batalkan seluruh order

**Aksi order**, lalu **Batalkan order** ("Perlu alasan"). Pilih **Pelanggan batal**, **Order ganda**, atau **Salah meja / tipe order**, lalu ketuk **Batalkan order**. Pesannya "Order dibatalkan." dan meja kosong. Item yang sudah dikirim diproses sebagai void.

- Order yang sudah memiliki pembayaran tidak dapat dibatalkan dan persetujuan tidak membantu: "Tab yang sudah dibayar tidak bisa dibatalkan."
- Tanpa izin pembatalan order, lembar persetujuan terbuka.

## Menutup shift saat ada order terbuka

Server menolak menutup shift selama masih ada order terbuka: "Shift hanya bisa ditutup setelah semua tab terbuka dibayar, dibatalkan, atau diserahkan." Tablet tidak dapat menyerahkan order ke shift lain. Bayar atau batalkan setiap order terlebih dahulu, lihat [Shift di tablet](/android/shifts).

## Pemecahan masalah

| Pesan | Penyebab | Solusi |
| --- | --- | --- |
| Galat dengan tombol coba lagi sebagai ganti denah | Denah tidak dapat dimuat. | Periksa koneksi, ketuk coba lagi. |
| "Meja Z tidak ditemukan." | Meja tidak ada di potret denah terakhir. | Tarik ke bawah untuk menyegarkan. |
| "Meja ini sudah punya tab yang terbuka." | Orang lain membukanya lebih dulu. | Buka meja lagi; sekarang membuka order itu. |
| "Meja ini milik outlet lain; tab tidak bisa dipindahkan antar-outlet." | Meja milik outlet lain. | Tidak berlaku di tablet. |
| "Item sudah dikirim — perubahan lewat void." | Anda menyimpan perubahan pada baris yang sudah dikirim. | Gunakan **Void item**. |
| "Tidak ada penyetuju yang memenuhi syarat untuk aksi ini." | Tidak ada penyetuju lain dengan PIN. | Lihat [Persetujuan](/android/approvals). |
| "Pembayaran ditolak: shift sudah ditutup. Buka shift untuk menerima pembayaran." | Shift tertutup. | Buka shift. |
