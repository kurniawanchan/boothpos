Aplikasi Android BoothPOS adalah kasir layar sentuh untuk kasir dan pelayan. Aplikasi ini mencatat pesanan, menerima pembayaran, mencetak struk dan tiket dapur, serta menjalankan shift kasir.

Aplikasi tidak menyimpan data sendiri. Semua pesanan, harga, stok, dan shift berada di server BoothPOS Anda, dan aplikasi membaca serta menulisnya lewat API yang sama dengan aplikasi web. Aplikasi ini **mengutamakan koneksi online** (online-first): tidak ada antrean pesanan lokal, sehingga tablet harus terhubung ke server untuk berjualan. Lihat [Offline dan sinkronisasi](/android/offline-and-sync).

## Sebelum mulai

- Tablet atau ponsel dengan **Android 8.0 atau lebih baru** (API level 26).
- Server BoothPOS yang dapat dijangkau tablet, lewat jaringan outlet atau online. Lihat [Siapkan terminal](/android/setup).
- Akun staf aktif dengan PIN 6 digit. Pemilik atau admin mengatur PIN di web. Lihat [Masuk dengan PIN](/android/pin-sign-in).
- Opsional: printer struk Bluetooth, yang dipasangkan lebih dulu di pengaturan Android. Lihat [Pencetakan](/android/printing).

<Note>
  Aplikasi dibagikan sebagai APK yang dibuat untuk instalasi Anda. Build tersebut membawa alamat server bawaan yang dipakai saat penyiapan. Jika penyiapan menyatakan aplikasi dibuat tanpa alamat bawaan, Anda memerlukan build lain dari administrator.
</Note>

## Hubungan aplikasi dengan server dan aplikasi web

| Pertanyaan | Jawaban |
| --- | --- |
| Di mana datanya? | Di server. Tablet hanya menyimpan pilihan terminalnya (outlet, nama terminal, alamat server) dan token sesinya. |
| Siapa yang mengatur harga, menu, staf, dan peran? | Pengguna back office di web. Lihat [Produk](/inventory/products), [Pengguna](/settings/users), dan [Peran](/settings/roles). |
| Apakah shift web dan aplikasi bentrok? | Tidak. Aplikasi dan web masing-masing punya satu shift terbuka per pengguna. Lihat [Shift di web](/operations/shifts). |
| Di outlet mana saya berjualan? | Di outlet yang dipilih saat penyiapan. Lihat [Outlet](/concepts/outlets). |

## Tata letak layar

Tata letak mengikuti lebar layar.

| Lebar | Tata letak |
| --- | --- |
| Di bawah 600 dp (ponsel) | Ringkas. Bilah navigasi bawah, judul lebih kecil, dan subjudul pendek berisi nama Anda dan status shift. Grid menu menampilkan 2 kolom. |
| 600 dp ke atas (tablet) | Navigation rail di kiri. Subjudul juga menampilkan peran Anda dan jam shift dibuka. Grid menu menampilkan 3 sampai 5 kolom sesuai lebar layar. |

Layar masuk, layar buka shift, editor pesanan, dan layar pembayaran memakai seluruh layar dan tidak punya rail atau bilah bawah.

### Item navigasi

| Item | Membuka apa |
| --- | --- |
| **Meja** | Denah meja untuk tab makan di tempat. Lihat [Meja](/android/tables). |
| **Counter** | Pesanan counter. Jika Anda sudah punya pesanan counter yang terbuka, aplikasi kembali ke pesanan itu; jika belum, aplikasi memulai pesanan baru. Lihat [Counter](/android/counter). |
| **Order** | Pesanan Anda yang terbuka dan yang selesai. Lencana menunjukkan jumlah yang masih terbuka. Lihat [Pesanan](/android/orders). |
| **Shift** | Pusat shift: total, kas masuk dan keluar, tutup shift. Lihat [Shift](/android/shifts). |
| **Perangkat** | Status koneksi, jam, dan printer. Hanya di rail, di bagian bawah. Layar ringkas membukanya dari tempat lain di aplikasi. |

Di rail, tombol bulat **+** di atas item memulai pesanan counter baru (**Order baru**).

<Note>
  ASUMSI: pada layar ringkas, bilah bawah hanya memuat Meja, Counter, Order, dan Shift, dan kode tidak menunjukkan jalan lain untuk membuka **Perangkat**. Periksa di ponsel sebelum Anda menyuruh staf memakainya di sana.
</Note>

## Header

Header menampilkan judul layar dan, di bawahnya, pengguna yang masuk beserta status shift: **Belum ada shift** atau **Shift terbuka**. Di kanan ada dua kontrol:

- **Chip koneksi.** Menampilkan **Online**, **Offline**, **Offline terbatas**, atau **Memeriksa koneksi…**. Warna peringatan dan ikon Wi-Fi tercoret berarti offline.
- **Tombol inisial.** Tombol bulat berisi dua inisial Anda mengunci aplikasi dan kembali ke layar PIN. Lihat [Ganti pengguna](/android/pin-sign-in).

## Mode gelap

Aplikasi beralih ke mode gelap sendiri dari pukul 18:00 sampai 05:59 menurut jam tablet. Pada siang hari aplikasi mengikuti pengaturan sistem Android. Tidak ada tombol untuk mengubahnya di dalam aplikasi.

## Tarik untuk menyegarkan

Di Meja, Order, Shift, layar laporan shift, dan **Perangkat**, tarik layar ke bawah untuk memuat ulang dari server. Menu counter punya tarik-untuk-segarkan sendiri, yang juga memuat ulang foto produk.

## Pemecahan masalah

| Pesan | Penyebab | Solusi |
| --- | --- | --- |
| **Memeriksa koneksi…** tidak hilang | Pemeriksaan server pertama belum selesai. | Tunggu beberapa detik, lalu buka **Perangkat** dan tekan **Periksa koneksi**. |
| Chip menampilkan **Offline** | Permintaan terakhir gagal di jaringan. | Periksa Wi-Fi dan server. Lihat [Offline dan sinkronisasi](/android/offline-and-sync). |
| Tidak ada item **Perangkat** di ponsel | Tata letak ringkas hanya punya empat item bawah. | ASUMSI: gunakan tablet atau tata letak rail untuk melihat status perangkat. |
