**Terminal** adalah satu tablet yang terdaftar di satu outlet dengan nama yang Anda pilih. Penyiapan hanya dilakukan sekali per tablet. Tidak perlu login pemilik atau admin: Anda memilih outlet dari daftar, lalu memilih atau mengetik nama terminal. Siapa pun yang memegang tablet dapat menyelesaikan penyiapan, jadi lakukan di tablet yang Anda kendalikan.

## Sebelum mulai

- Tablet dan server harus saling terjangkau. Pada peluncuran pertama, aplikasi mencari server sendiri.
- Admin harus sudah mengisi alamat server di pengaturan web (**Alamat server**). Lihat [Pengaturan umum](/settings/general).
- Outlet harus aktif di server. Lihat [Outlet](/people/outlets).
- Tentukan nama terminal. Nama harus unik di dalam outlet, jadi pakai nama per perangkat, misalnya "Kasir Depan".

## Siapkan tablet

<Steps>
  <Step title="Buka aplikasi">
    Tablet tanpa terminal tersimpan membuka **Siapkan terminal**: "Pilih outlet, lalu pilih atau ketik nama terminal ini."
  </Step>
  <Step title="Tunggu pencarian server">
    Aplikasi menampilkan **Mencari server…**, lalu **Memuat outlet…**. Tidak ada yang perlu diketik di sini; tidak ada kolom alamat server.
  </Step>
  <Step title="Pilih outlet">
    Pilih satu **Outlet** (tombol radio). Pada instalasi satu outlet, outlet sudah terpilih.
  </Step>
  <Step title="Pilih atau ketik terminal">
    Kolom **Terminal** muncul hanya setelah outlet dipilih. Pilih terminal yang ada di daftar, atau ketik di **Atau ketik nama terminal baru** (atau ketik di **Nama terminal (mis. Kasir Depan)** bila outlet belum punya terminal).
  </Step>
  <Step title="Lanjutkan">
    Ketuk **Lanjut**. Tablet berpindah ke layar PIN. Lihat [Masuk dengan PIN](/android/pin-sign-in).
  </Step>
</Steps>

### Aturan nama

- Nama yang diketik menang atas yang dipilih. Mengetik menghapus pilihan radio.
- Nama dipangkas spasinya. **Lanjut** tetap nonaktif sampai outlet dipilih dan nama tidak kosong.
- Jika Anda mengetik nama yang sudah dimiliki terminal aktif di outlet itu, server mengembalikan terminal tersebut, bukan menolak. Dua tablet dengan nama yang sama karenanya berbagi satu catatan terminal.
- Kolom nama sengaja dimulai kosong, agar nama bawaan tidak bentrok di tablet kedua.
- Mengganti outlet menghapus terminal terpilih dan nama yang diketik.

## Cara alamat server ditemukan

Aplikasi punya alamat bawaan: lokal dulu, lalu online. Aplikasi bertanya kepada alamat pertama yang menjawab tentang alamat mana yang dipilih admin di web, lalu menyimpan alamat itu di tablet.

- Jika admin memilih **Online** dan membiarkan alamat online kosong, alamat online bawaan build dipakai, tetapi hanya setelah terbukti terjangkau.
- Alamat dibaca sekali. Tablet yang sudah punya alamat tetap memakainya, bahkan setelah penyiapan ulang. Memindahkan tablet antara server lokal dan online berarti menghapus data aplikasi di tablet, lalu menyiapkannya lagi.

## Ubah terminal nanti

Di layar PIN, ketuk **Ganti outlet / terminal**. Pada tata letak tablet, aksi yang sama adalah ikon roda gigi di kanan atas panel kiri. Ini membuka kembali penyiapan.

- **Batal** muncul hanya bila tablet sudah menyimpan outlet dan terminal. Tombol ini kembali ke layar PIN dan pilihan lama tetap berlaku.
- Sampai Anda mengetuk **Lanjut**, pilihan lama tetap berlaku.

## Saat tablet dikembalikan ke penyiapan

Tablet menghapus terminal tersimpan dan kembali ke **Siapkan terminal** dengan pesan merah ketika server menyatakan terminal tidak berlaku lagi:

| Pesan | Kapan |
| --- | --- |
| "Terminal ini tidak berlaku lagi. Pilih outlet dan terminal lagi." | Saat aplikasi mulai, terminal tersimpan sudah tidak ada di outletnya, atau masuk dengan PIN ditolak karena terminal. |
| "Terminal ini sudah dicabut. Pilih outlet dan terminal lagi." | Admin mencabut terminal saat tablet dipakai dan pengguna sudah keluar dari alur pesanan. |
| "Terminal ini dicabut. Selesaikan order ini; setelah itu pilih terminal lagi." | Dicabut saat pengguna berada di layar editor, pembayaran, atau selesai. Tab yang sedang berjalan dapat diselesaikan lebih dulu. |

Gangguan jaringan tidak pernah menghapus terminal. Hanya jawaban dari server yang menghapusnya.

## Pemecahan masalah

| Pesan | Penyebab | Solusi |
| --- | --- | --- |
| "Alamat server belum diatur. Minta admin mengisinya di web (Pengaturan › Server address), lalu coba lagi." | Server menjawab, tetapi alamat yang dipilih admin kosong. | Admin mengisinya di web, lalu ketuk **Coba lagi**. |
| "Server tidak terjangkau. Pastikan tablet satu jaringan dengan server outlet atau punya internet, lalu coba lagi." | Tidak ada alamat bawaan yang menjawab, atau alamat yang dipilih tidak menjawab. | Periksa Wi-Fi atau internet, lalu **Coba lagi**. |
| "Aplikasi ini dibuat tanpa alamat server bawaan. Hubungi admin untuk versi aplikasi yang benar." | APK tidak punya alamat bawaan. | Pasang build yang benar. Tidak ada tombol coba lagi. |
| "Belum ada outlet aktif di server. Minta admin menambahkannya di web, lalu coba lagi." | Tidak ada outlet aktif. | Tambahkan atau aktifkan outlet di web, lalu **Coba lagi**. |
| **Lanjut** berwarna abu-abu | Outlet belum dipilih, nama kosong, atau terminal masih dimuat. | Pilih outlet dan isi nama. |
| Galat di bawah **Lanjut** | Server menolak pendaftaran. Pesannya berasal dari server. | Baca pesannya, perbaiki nama atau outlet, coba lagi. |
