Aplikasi Android **mengutamakan koneksi online** (online-first). Aplikasi tidak menyimpan antrean pesanan atau pembayaran untuk dikirim nanti. Setiap aksi dikirim ke server saat Anda menekannya, dan server adalah catatan resminya. Halaman ini menjelaskan apa yang Anda lihat saat koneksi putus dan cara memeriksanya.

## Sebelum mulai

- Semua orang yang sudah masuk dapat membuka layar **Perangkat** dan melihat status koneksi. Tidak perlu izin khusus.
- Masalah Wi-Fi adalah penyebab yang paling umum. Server juga mungkin mati atau berada di jaringan lain.

## Status koneksi

Chip di header menampilkan status yang terakhir diketahui aplikasi.

| Chip | Artinya |
| --- | --- |
| **Memeriksa koneksi…** | Belum ada yang diperiksa sejak aplikasi dimulai. |
| **Online** | Permintaan terakhir sampai ke server. |
| **Offline** | Permintaan terakhir gagal di jaringan (tidak ada jawaban, waktu habis). |
| **Offline terbatas** | Dicadangkan untuk tablet yang offline dalam waktu lama. Lihat di bawah. |

Hanya kegagalan jaringan yang mengubah chip menjadi **Offline**. Penolakan seperti 401, 403, 409, atau 422 tetap membuktikan bahwa server menjawab, sehingga chip tetap **Online** dan pesannya ditampilkan.

<Warning>
  Chip juga dapat diketuk dan berganti status secara manual. Ini sisa dari prototipe desain. Permintaan berikutnya dari aplikasi mengembalikannya ke kondisi sebenarnya. Beri tahu staf agar tidak mengandalkan ketukan.
</Warning>

### Offline terbatas dan banner

Saat status **Offline terbatas**, banner kuning muncul di bawah header: "Perangkat offline lebih dari 4 jam. Order baru perlu persetujuan Outlet Manager dan tunai baru ditolak. EDC tetap bisa dipakai."

<Note>
  ASUMSI: ini kebijakan yang dirancang, bukan yang ditegakkan. Kode tidak pernah memindahkan aplikasi ke **Offline terbatas** sendiri, dan tidak ada aturan di aplikasi maupun server yang memblokir tunai atau meminta persetujuan setelah 4 jam offline. Hanya ketukan manual pada chip yang menampilkan banner. Jangan beri tahu staf bahwa tunai diblokir saat offline.
</Note>

## Yang terjadi pada aksi saat offline

Tidak ada yang disimpan untuk nanti. Banyak aksi (misalnya diskon, refund, tutup shift) mencoba hingga tiga kali saat jaringan gagal, dengan jeda singkat, lalu berhenti. Aksi lain gagal pada percobaan pertama.

| Aksi | Saat server tidak terjangkau |
| --- | --- |
| Masuk dengan PIN | Gagal dengan pesan jaringan. Anda tidak dapat masuk. |
| Membuka menu, denah, pesanan | Menampilkan data yang terakhir dimuat, atau kartu galat dengan **Coba lagi** jika belum ada yang termuat. |
| Kirim item, terima pembayaran, diskon, void | Gagal dengan pesan jaringan di toast. Tidak ada yang tercatat. Tekan lagi setelah online. |
| Tutup shift | Toast: "Koneksi terputus. Kirim hitungan lagi; server tidak akan menutup dua kali." Kirim hitungan lagi. Server tidak akan menutup dua kali. |
| Persetujuan | Daftar penyetuju tidak dapat dimuat dan PIN tidak dapat diperiksa. Lihat [Persetujuan](/android/approvals). |
| Pencetakan | Tablet berbicara langsung dengan printer. ASUMSI: mencetak dokumen yang sudah termuat berfungsi saat offline, tetapi pesanan atau pembayaran di baliknya tetap membutuhkan server. Lihat [Pencetakan](/android/printing). |

Aksi yang menyangkut uang atau mengubah pesanan membawa kunci sekali pakai. Percobaan ulang setelah balasan terputus karenanya memakai kunci yang sama, dan server menjawab dengan hasil tersimpan alih-alih mencatatnya dua kali.

<Tip>
  Jika Anda tidak yakin pembayaran atau penutupan sudah berhasil, buka **Order** atau **Shift** dan tarik ke bawah untuk memuat ulang sebelum mencoba lagi.
</Tip>

## Layar Perangkat

Buka **Perangkat** (**Perangkat & sinkron**) dari rail. **Periksa koneksi** mengirim heartbeat sekarang, tanpa menunggu heartbeat berikutnya.

| Kartu | Menampilkan | Catatan |
| --- | --- | --- |
| **Koneksi** | **Belum terhubung**, **Terhubung**, atau **Terputus** | Ditambah "Heartbeat terakhir OK \{HH:mm:ss\}". **Terputus** menambahkan "server tidak terjangkau". |
| **Jam perangkat** | Selisih dalam detik dari server | "Dalam batas ±5 dtk", atau "Selisih lebih dari 5 dtk — koreksi jam perangkat". |
| **Rilis menu** | Rilis menu yang dilaporkan server | **Belum ada rilis** bila tidak ada. |
| **Siap EOD (perangkat ini)** | **Siap** bila tidak ada shift terbuka, selain itu **Belum** | Akhir hari (end of day) dijalankan manajer outlet di back office. |

Di bawah kartu ada panel printer. Lihat [Pencetakan](/android/printing).

## Heartbeat

Selama aplikasi tampil di depan dan ada yang masuk, aplikasi mengirim heartbeat ke server setiap 60 detik. Satu heartbeat juga dikirim tepat setelah masuk. Heartbeat melaporkan versi aplikasi dan mengembalikan waktu server, sehingga selisih jam dapat ditampilkan. Heartbeat juga menyegarkan nama terminal, sehingga penggantian nama oleh admin di web muncul di tablet. Heartbeat berhenti saat aplikasi berpindah ke latar belakang. Di layar PIN tidak ada sesi, jadi aplikasi memuat ulang daftar staf setiap 10 detik agar chip tetap jujur.

Heartbeat yang gagal mempertahankan nilai baik yang terakhir dan hanya mengubah status menjadi **Terputus** dan chip menjadi **Offline** (hanya untuk kegagalan jaringan). Jika server menjawab bahwa terminal dicabut, lihat [Siapkan terminal](/android/setup).

## Tarik untuk menyegarkan

Tarik layar berikut ke bawah untuk memuat ulang: **Meja**, **Order**, **Shift**, layar laporan X dan tutup shift, serta **Perangkat** (yang memeriksa ulang printer). Denah meja juga memuat ulang sendiri setiap beberapa detik. Penyegaran yang gagal mempertahankan data yang sudah ada di layar.

## Pemecahan masalah

| Pesan | Penyebab | Solusi |
| --- | --- | --- |
| Chip **Offline** | Kegagalan jaringan pada permintaan terakhir. | Periksa Wi-Fi, lalu tekan **Periksa koneksi**. |
| **Belum terhubung** | Belum ada heartbeat yang berhasil sejak masuk. | Tekan **Periksa koneksi**; periksa server. |
| "Selisih lebih dari 5 dtk — koreksi jam perangkat" | Jam tablet berbeda dari server. | Aktifkan tanggal dan waktu otomatis di pengaturan Android. |
| "Sesi berakhir. Masuk kembali." | Sesi PIN tidak berlaku lagi. | Masuk lagi. Lihat [Masuk dengan PIN](/android/pin-sign-in). |
| "Koneksi terputus. Kirim hitungan lagi…" | Jaringan putus saat menutup shift. | Kirim hitungan lagi. |
